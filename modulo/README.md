# Sistema de Gestión de Datos de Empleados

## Funciones del sistema

- Agregar empleado.
- Listar empleados.
- Buscar empleado por ID.
- Eliminar empleado.
- Mostrar resumen.
- Exportar datos a un archivo CSV.

## Tecnologías utilizadas

- Python
- Módulos
- Funciones
- Listas
- Diccionarios
- Conjuntos (Set)
- Archivos CSV

## Archivos del proyecto

- main.py
- funciones.py
- empleados.csv
