Proyecto básico del Módulo 2: Fundamentos del desarrollo Front-End.

## Archivos
- index.html: entrada del proyecto.
- login.html: inicio de sesión.
- menu.html: menú principal y saldo.
- deposit.html: depósito de dinero.
- sendmoney.html: envío de dinero y agregar contactos.
- transactions.html: últimos movimientos y filtro.
- css/styles.css: estilos básicos y media query.
- js/script.js: funciones, eventos y jQuery.

## Tecnologías usadas
- HTML
- CSS
- Bootstrap
- JavaScript
- jQuery
